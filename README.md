# Prathmesh Panmand — Portfolio

Modern responsive React/Vite portfolio for Prathmesh Panmand.

## Stack
- React
- Vite
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Deploy

Recommended: push this repository to GitHub and import it into Vercel. Vercel detects Vite automatically.
